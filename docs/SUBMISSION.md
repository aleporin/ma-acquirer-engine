# Submission guide

## Review route

1. Read [README.md](../README.md) for scope, commands, observations, and limitations.
2. Run `make run` without keys and open the printed report path.
3. Inspect one buyer's thesis, precedent IDs, valuation comps, risks, and conviction.
   Follow its citations into the evidence appendix.
4. Read [EXECUTION.md](../EXECUTION.md) in order, then
   [DECISIONS.md](DECISIONS.md) and [EVALS.md](EVALS.md).
5. Inspect the conventional-commit history and the separate test/implementation
   commits. Historical scorecards retain failed measurements.

The minimum setup is the pinned uv version and a standard `make` command.
The first run can download Python and dependencies. No provider account is needed
for the supplied replay. The recorded [demo](DEMO.md) also explains the flow.

## Contents

- Source, tests, configuration, prompts, and dependency lockfile.
- Original transaction CSV and curated response archive for the default target.
- Ten-buyer sample HTML, Markdown, and structured JSON.
- Committed evaluation results and their provenance.
- Documentation and demonstration materials.

Use the private repository or the prepared ZIP with git history. Local environments,
working run directories, credentials, private planning documents, and worktree
metadata do not belong in the delivery package.

## Status that must remain visible

The latest complete live observation produced 10/10 verified pages and 79/79
numeric claims, but took 72.65 seconds and cost $1.022239 in returned usage.
Ranking has not demonstrated lift over popularity. All default convictions are
Medium. Independent human/judge calibration and a measured judge-prompt iteration
remain unfinished. Replay does not change those observations.
The archived Francisco thesis also misstates the target's margin position;
the known qualitative defect and its measured values are in [EVALS.md](EVALS.md).

## Final human checks

- Read the README end to end and confirm the limitations are stated accurately.
- Walk through one draft, a tool return, a validation failure, and its repair.
- Explain why ranking/conviction are deterministic while fresh prose can vary.
- Explain what a scorecard pass proves and what it does not.
- Complete blind calibration votes before viewing any future judge results.
- Choose the intended recipients before sharing the private repository or ZIP.

The material is ready for inspection without API keys. A public deployment or a
change in repository visibility is unnecessary.
